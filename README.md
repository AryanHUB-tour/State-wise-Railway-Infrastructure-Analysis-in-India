# State-wise-Railway-Infrastructure-Analysis-in-India 
I worked on a Power BI Project | Railway Infrastructure Analysis State-wise in India

Recently, I created a Power BI dashboard based on NDAP data for analysing railway infrastructure in India, based on the various Indian states.

1. Key findings:
• States like Uttar Pradesh, Maharashtra, and West Bengal rank first when it comes to railway track length
• Very little railway infrastructure exists in the North-Eastern states of India
• There is a marked difference between railway routes and running tracks
• Various top states form a major portion of India’s rail network

2. Tech Stack
The dashboard was built using these tools 
• PowerBI Desktop - Main data visualisation platform used for report creation
• Power Query - Data transformation, cleaning and reshaping 
• DAX - Used for calculated measures, dynamic visuals and logics
• Data Modelling - Relationships established among tables
• File Format - .pbix for development and .png for dashboard previews

4. Features of the dashboard:
• Key Performance Indicator Cards for easy understanding
• Analysis of the top and bottom states
• Comparison between routes and running tracks
• Percentage share of top states forming India’s railway network

5. Data Source
Source: State wise railway track data via NDAP
https://ndap.niti.gov.in/dataset/7235
